# Axioma Web — Portal Web Corporativo (axiomaweb.cl)

Plataforma comercial y portal de autogestión para **Axioma Web**, agencia de desarrollo web e ingeniería corporativa para Pymes en Chile.

---

## 🚀 Características Principales

### Landing Page & Cotizador
- **Carrusel de Banners Interactivo**: 5 slides con imágenes HD únicas, controles discretos de navegación (`<` y `>`), indicadores estilo Instagram y pausa automática al pasar el mouse (*Pause on Hover*).
- **Cotizador Instantáneo para Pymes**: Cálculo transparente de presupuestos desde $149.990 CLP con opciones adicionales (Dominio .CL gratis, Posicionamiento en Google, Mantención).
- **Canales de Atención Directa**: Botón principal de cotización instantánea conectado a WhatsApp con mensaje preformateado.
- **Modo Claro / Oscuro**: Selector de tema con contraste Slate 900 / Navy de alta legibilidad.
- **Portafolio en Mockup Laptop**: Muestra de soluciones web reales (E-Commerce Pymes, Gimnasios & Reservas, Estética & Agenda).
- **Sección Nosotros & Canales Institucionales**: Enlaces a portafolio de proyectos y botón directo a Email de contacto.
- **FAQ Corporativo**: Acordeón interactivo para resolución inmediata de dudas comerciales.

### Portal de Cliente & Dashboard
- Dashboard autoadministrable con carga diferida (`React.lazy`).
- Solicitud y seguimiento de requerimientos de diseño o código.
- Mensajería directa con el equipo técnico de soporte.
- Agendamiento de reuniones y mantención.

### Panel Admin Maestro
- Visión general corporativa para gestión de clientes y solicitudes.

## 📋 Instalación y Ejecución Local

```bash
# 1. Clonar el repositorio
git clone https://github.com/Cristobal-Sandoval/Axiomaweb.cl.git
cd Axiomaweb.cl

# 2. Instalar dependencias
npm install

# 3. Servidor de desarrollo local
npm run dev

# 4. Ejecutar tests unitarios
npm test

# 5. Compilar para producción
npm run build
```
